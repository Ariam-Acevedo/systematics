# Snowstorm

Utilities for loading data, computing snowstorm-style variations, and saving plots with filenames based on the varied variables and dtype.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Notes

- The local `h5flow/` folder is ignored because it is its own git repository.
- Generated plots are saved in `plots/` by default.
- If you use `snowstorm_functions.py`, make sure `h5flow` is installed or available in your Python path.
